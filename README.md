# Simple Calculator Project

## Overview

This is a basic **Simple Calculator** project created using **HTML** and **JavaScript**.
It performs four basic mathematical operations:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)




### JavaScript

JavaScript is used to perform calculations and display output.

Concepts used:

* **Functions** → Separate functions for each operation

  * `add()`
  * `subtract()`
  * `multiply()`
  * `divide()`

* **DOM Manipulation**

  * `document.getElementById()` → To access input values

* **Number Conversion**

  * `Number()` → Converts input values into numbers

* **Displaying Output**

  * `innerHTML` → Shows the result on the webpage

---

## How It Works

1. User enters the first number
2. User enters the second number
3. User clicks any operation button
4. JavaScript function performs calculation
5. Result is displayed on the screen
